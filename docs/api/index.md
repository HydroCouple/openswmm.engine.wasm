# API reference

The reference is generated from the TypeScript sources (`src/js/`) with TypeDoc each time the
manual is built, from the package's entry point `src/js/index.ts`: every symbol listed here is
importable from `@hydrocouple/openswmm-engine-wasm`. Members follow the Python bindings in
camelCase; the [engine's Python guide](https://www.hydrocouple.org/openswmm.engine/python/) has
longer descriptions of the same members.
